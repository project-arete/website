Get the Arete Apps

Ready-to-run desktop applications for macOS, Windows, and Linux. Point them at any realm — your own orchestrator on Arete Hosting is the fastest way to have one.

A note about signing. These apps are open source and not yet code-signed, so your operating system will object the first time you run them. That is expected. On macOS (Sequoia and later) the warning claims the app “is damaged and can’t be opened” — it isn’t damaged; that is how macOS now phrases the quarantine flag on unsigned downloads, and right-click → Open no longer bypasses it. Clear the flag once in Terminal and launch normally:

xattr -cr "/Applications/Arete Widgets.app"  or  xattr -cr "/Applications/Arete Monitor.app"

(On older macOS versions, right-click the app and choose Open.) On Windows, click More info → Run anyway on the SmartScreen prompt; on Linux, mark the AppImage executable (chmod +x) before launching. Each app’s Install guide below walks through this step by step.

Every app comes in four flavours: installers for Windows, macOS, and Linux — or the web app (PWA): nothing to install, no signing warnings, automatic updates. On a phone, open the web app and add it to your home screen (iPhone: Share → Add to Home Screen; Android: Install app). Web apps need the realm to present a valid certificate — every *.aretehosting.com realm qualifies.
